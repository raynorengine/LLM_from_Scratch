# 파트1 주피터 노트북

강의에서 C로 만든 n-그램 언어 모델을 파이썬으로 짧게 다시 만들어 보는 노트북입니다.
강의 내용을 전부 담지는 않았습니다. 영상에서 본 결과를 직접 돌려서 확인할 수 있는 최소한의 예제만 넣었습니다.

| 노트북 | 해당 강의 | 실행 시간 | 메모리 |
|---|---|---|---|
| `01_글자빈도와샘플링.ipynb` | 04-02. 글자 빈도 통계 | 몇 초 | 100MB 이하 |
| `02_엔그램으로단어만들기.ipynb` | 04-03. 바이그램 · 04-04. 트라이그램 · 04-05. N-그램 | 20초 안팎 | 1GB 이하 |
| `03_엔그램으로문장만들기.ipynb` | 04-06. 문장 생성 · 04-07. 형태소 분석 | 30초 안팎 | 약 1GB |

GPU는 필요 없습니다.

## 준비

- 파이썬 3.10 이상과 주피터가 필요합니다. 아나콘다를 설치했다면 둘 다 들어 있습니다.
- `03`만 형태소 분석기 키위(Kiwi)가 필요합니다.

```bash
pip install -r requirements.txt
```

## 실행

이 폴더에서 주피터를 실행하고 노트북을 번호 순서대로 엽니다. 메뉴의 Run All(모두 실행)을 누르면 위에서 아래까지 한 번에 돌아갑니다.

```bash
jupyter lab
```

실행 결과가 노트북에 저장돼 있어서 돌리지 않고 읽기만 해도 됩니다.

## 데이터 (`data/`)

| 파일 | 내용 |
|---|---|
| `words.txt` (5MB) | 표준국어대사전 표제어 420,309개. [korean-word-game/db](https://github.com/korean-word-game/db)(2018-11-13 수집)에서 한글이 아닌 문자가 든 단어를 빼고 중복을 지운 것입니다. 낱말과 품사만 모은 자료라 저작권이 없다고 원 저장소가 밝히고 있습니다. |
| `sf_novels.txt` (4.5MB) | [위키문헌](https://ko.wikisource.org)에서 받은 SF 소설 27편에서 출판 정보·한자·특수 기호를 지우고 한 파일로 합친 것입니다. |

## 결과가 조금 다르게 나올 때

모든 노트북은 난수 시드를 고정해 두었습니다. 같은 환경이면 저장된 결과와 똑같이 나옵니다.

키위 버전이 다르면 형태소가 다르게 나뉘는 곳이 생겨서 `03`의 문장과 수치가 조금 달라질 수 있습니다.
저장된 결과는 파이썬 3.13과 kiwipiepy 0.23.2로 만들었습니다.
