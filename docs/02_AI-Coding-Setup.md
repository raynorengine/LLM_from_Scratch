# AI 코딩 준비 (챕터2-2)

## 실습 환경
- 주 언어: **C**. 전처리·도구 작업은 **Python** 보조 사용
- 에디터: Visual Studio Code (Claude/Codex/Copilot 등은 익스텐션으로 설치)
- 코딩 AI: **Claude Code — Opus 모델 기준**
  - Gemini, ChatGPT 등도 사용 가능하나 모델 특성이 달라 진행 과정이 달라짐
  - 다양한 모델을 써보는 것은 AI 활용 연습으로 권장

## AI 사용 팁

### 같은 입력에도 다른 응답
- 두 세션에 동일 입력 → 서로 다른 대답
- 원인: LLM은 **확률적 샘플링(stochastic sampling)** 사용 → 본질적으로 **비결정적(non-deterministic)**

### 모델 성능 차이
- Haiku: 부족
- Sonnet: 틀이 잡혀 있을 때 양호
- **Opus: 가장 자율적으로 작동**
- 사례: 컴파일러가 없을 때 Opus는 스스로 대안을 찾아 해결, 하위 모델은 사용자에게 해결을 맡김

### 컨텍스트의 점진적 구축
- 한 번 지시하면 **세션 내에서 계속 그 방식으로 작성**
- 지시를 쌓아가며 작업 환경을 정비할 수 있음

### 시행착오 기록
- AI에게 시행착오를 **Markdown 파일에 기록**하라고 지시하면 자동 정리
- **사람이 보기 위한 것이 아니라, 나중에 AI가 참고하도록 남기는 것**

### 권한 설정 자동화
- `.claude/settings.local.json`에 읽기/쓰기/실행을 허용으로 설정 → 매번 묻지 않음
- 이 설정 파일도 AI에게 만들어달라고 하면 됨
