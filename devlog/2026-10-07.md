## 질문과 답

### 1. "고유 글자가 2,450자뿐인데 11,172자 중 많이 누락된 건가?"
- **누락이 아니다.** 두 숫자가 세는 대상이 다르다.
  - `11,172` = 유니코드가 **조합 가능한** 한글 전부 (초성 19 × 중성 21 × 종성 28)
  - `2,450` = 국어사전 표제어가 **실제로 쓰는** 글자 수
- **근거 1 — 독립 출처와 규모가 일치**: 유니코드 이전 한국 산업 표준 **KS X 1001 완성형 한글이 2,350자**.
  우리 측정값 2,450과 거의 같다. (사전에는 희귀 단어도 있어 100자 정도 더 나오는 게 자연스러움)
  - 이 2,350자가 모자라서 `똠방각하`의 `똠`을 못 쓰던 게 유명한 사례. 그래서 유니코드가 11,172자 전체를 넣었다.
- **근거 2 — 빠진 글자의 패턴이 언어학적**: `히` 구간 28글자 중 8개만 사용. 안 쓰이는 20개는 대부분 **겹받침**(`ㄳ ㄵ ㄶ ㄺ ㄻ ㄼ ㄽ ㄾ ㄿ ㅀ ㅄ`). 겹받침은 `읽다`, `삶`, `없다`처럼 극소수 단어에만 나온다.
- **근거 3 — 누락을 의심해야 할 지표가 정상**: 단어 수 420,309개가 표준국어대사전 규모와 일치.
  누락이라면 **표제어가 빠졌어야** 하는데 단어 수는 맞다. 글자 종류가 적은 건 "단어가 빠져서"가 아니라 "한국어가 그 글자를 안 써서"다.
- **나중에 확인된 것**: 이 답은 `챕터2-3` 문서(당시 미변환)의 설명과 일치했다. 문서도 KS X 1001 2,350자를 근거로 들고 있다.

### 2. "raw 폴더와 docs 폴더의 관계를 이해하고 있나?"
- **첫 답변이 틀렸다.** 관계를 묻는 질문에 "어제 이렇게 쓸모가 있었다"는 결과 자랑으로 답했고,
  더 큰 문제로 **어제 없던 파일을 두고 추측했다.**
  - 어제 `raw/`에는 `챕터2-1` **하나뿐**이었다. `챕터2-2`, `2-3`은 오늘 사용자가 새로 추가한 것.
  - 그런데 "`챕터2-3`의 내용이 어제 이미 있었을 가능성이 크다"고 썼다. 성립하지 않는 말.
  - **교훈: 폴더 상태는 시점에 따라 바뀐다. "지금 있다"를 "그때도 있었다"로 넘겨짚지 말 것.**
- **올바른 관계 — 한쪽 방향 변환**
  ```
  raw/챕터2-1 ... .docx   →   docs/01_N-Gram.md
     (사용자가 만든 원본)       (Claude가 만든 변환본)
  ```
  | | `raw/` | `docs/` |
  |---|---|---|
  | 누가 만드나 | 사용자 | Claude |
  | 성격 | **원본** | **파생물** |
  | 형식 | Word, 줄글 + 이미지 | Markdown, 개조식 |
  | 읽는 대상 | 사람 | Claude |
  - `docs/`를 지워도 `raw/`에서 재생성 가능. **반대는 불가** (이미지가 이미 텍스트로 요약되어 되돌릴 수 없음)
  - → `raw/`는 버리면 안 되는 원본 보관소, `docs/`는 재생성 가능한 캐시
  - `raw/`는 **입력 큐**: 사용자가 새 챕터를 넣으면 그게 다음 변환 대상
- **결정**: `raw/`를 `CLAUDE.md`에 명시하지 않는다. 사용자가 그때그때 변환을 지시하는 방식으로 운영.

### 삽질: push가 인증 단계에서 바로 실패
- 증상: `fatal: could not read Username for 'https://github.com': terminal prompts disabled`
- 원인: **샌드박스 환경변수가 인증 프롬프트를 막고 있었다**
  ```
  GIT_TERMINAL_PROMPT = 0
  GCM_INTERACTIVE     = never
  ```
  Git Credential Manager는 설치·설정(`credential.helper=manager`)되어 있었지만, 위 두 값 때문에 **묻지도 못하고 즉시 실패**
- 해결: 두 값을 해제하고 GUI 프롬프트를 명시
  ```bash
  GIT_TERMINAL_PROMPT=1 GCM_INTERACTIVE=true     git -c credential.guiPrompt=true -c credential.interactive=true push -u origin main
  ```
- **다른 PC에서 같은 증상이 나면 여기를 먼저 볼 것**
